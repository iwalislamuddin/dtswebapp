title: Rilis stabil pertama — 37 tool dalam 7 kategori

- **37 kalkulator sesuai SNI:** Beton, Baja, Struktur Bawah, Geoteknik, Pembebanan, Hidraulika, dan Analisis Struktur,
  dengan mesin hitung yang ditulis ulang dan diuji terhadap versi sebelumnya.
- **Tampilan baru:** bergaya aplikasi desktop dengan menu File & Help, navigasi per kategori, tab Input dan Detail,
  tema terang & gelap, serta logo dan ikon baru. Di ponsel, isian angka punya tombol −/+ dan pilihan nilai umum.
- **Akun Edifisia:** masuk dengan email atau Google — satu akun untuk semua aplikasi Edifisia.
- **Simpan & Buka Pekerjaan (Premium):** simpan input ke akun Edifisia (cloud, hingga 50 pekerjaan, bisa dibuka dari
  perangkat lain) atau sebagai file .edft.
- **Laporan berumus:** tab Detail menampilkan langkah perhitungan lengkap; laporan PDF bergambar (Premium) tersedia
  dalam Bahasa Indonesia dan Inggris.
- **Daya dukung tiang metode O'Neill & Reese:** Daya Dukung Tiang (SPT) kini memakai metode FHWA untuk tiang bor ini,
  menggantikan metode SPT Meyerhof. Lempung: tahanan selimut α·cu dan ujung Nc*·cu hingga 3.830 kPa. Pasir: tahanan
  selimut β·σ′v hingga 200 kPa dengan β dari kedalaman dan N-SPT, ujung 57,5N hingga 4.300 kPa. Ada opsi untuk
  mengabaikan selimut lempung 1,5 m teratas dan 1D terbawah, dan nilai cu yang Anda isi ikut dihitung. Tool ini juga
  dilengkapi tabel N-SPT, pile cut-off, gesekan negatif, kapasitas tarik, dan penulangan tiang.
- **Tool baru:** Beban Gempa (SNI 1726:2019) dari peta gempa Indonesia lengkap dengan spektrum desain, KDS, dan geser
  dasar; Cek Desain Balok Beton (lentur, geser, torsi).
- **Peningkatan tool:** Base Plate sendi & jepit; Diagram P–M Kolom untuk banyak kombinasi beban; Pile Cap dengan
  koordinat tiang bebas dan sketsa penulangan; Beban Angin untuk gudang pelana, atap bebas, dan rangka terbuka.
- **Tautan contoh perhitungan:** contoh dari halaman Coba di edifisia.com terbuka di Civil Tools dengan input yang
  sudah terisi.

Pekerjaan tersimpan yang memakai metode SPT lama otomatis dibuka dengan metode O'Neill & Reese, sehingga hasilnya bisa
berbeda dari sebelumnya. Periksa kembali sebelum dipakai.
